    第 1 章 · Agent 基础¶

    第 1 章 · Agent 基础

    难度 ⭐ 入门 · 一句话：Agent = LLM + 上下文 + 工具 = 大脑 + 眼睛 + 手脚。

    🗺️ 本章地图¶

    flowchart TD
  A["Agent = LLM + 上下文 + 工具"] --> B["🧠 大脑 · LLM<br/>理解意图 · 拆解任务 · 做决策"]
  A --> C["👀 眼睛 · 上下文<br/>每个决策点能看到的一切"]
  A --> D["🦾 手脚 · 工具<br/>感知 · 执行 · 协作"]
  D --> E["工具调用四步<br/>声明 → 决策 → 执行 → 回填"]
  B --> F["ReAct 循环<br/>思考 → 行动 → 观察 → 再思考"]
  B --> G["Harness 工程<br/>马具 · 把能力引到正路上"]

    💎 核心概念¶

    🧠 大脑 · LLM

    不只是模型参数，而是整个决策内核：理解意图、拆解任务、持续判断下一步。策略

    👀 眼睛 · 上下文

    Agent 在每个决策点能看到的信息：环境、记忆、领域知识、自身状态。观察空间

    🦾 手脚 · 工具

    Agent 能做的所有事：预定义工具、按需 Skills、动态生成代码、委托子 Agent。动作空间

    🔧 工具调用

    四步：先告诉模型有哪些工具 → 模型决定调哪个、传什么参数 → 结果追加回上下文 → 模型接着决策。Tool Calling

    🧩 五类工具

    感知（看）、执行（做）、协作（找别人）、用户沟通（说话）、事件触发（被叫醒）。第 4 章细讲

    🔄 ReAct 循环

    思考 → 行动 → 观察 → 再思考，一直循环到任务完成。这是所有 Agent 的心脏。核心循环

    🐎 Harness 工程

    Harness 是马具——不限制马的奔跑，而是把力量引导到正确方向。上下文管理、工具接口、安全约束都属于它。竞争力所在

    🖼️ 关键图：ReAct 循环长什么样¶

    图：一个「多币种汇总」任务的真实 ReAct 循环轨迹 · 来自原书图 1-3

    看到一条条「思考 → 调用工具 → 观察结果 → 再思考」的链子了吗？每走一步，上下文里就多一条信息，大脑的决策依据就更充足——这就是 Agent 工作的基本节拍。

    🫧 打个比方¶

    🦾 没有工具的模型，只能「纸上谈兵」

    模型再聪明，没有工具就只能说、不能做——它知道该查天气，但查不到。有了工具，它才能从「被动的观察者」变成「主动的执行者」。所以本书有个观点：很多看起来"需要更聪明模型"的问题，其实是接口问题——把数据装进上下文、把操作封装成工具，原本不可解的任务就可能变得可解。

    📖 关键术语¶

    术语 白话解释
    Agent 能自主规划步骤、调用工具、根据结果调整策略的智能系统
    LLM 大语言模型，Agent 的「大脑」
    上下文 Agent 决策时能看到的所有信息
    工具 Agent 能做的所有事情的集合
    工具调用 模型用结构化方式请求调用外部工具的能力
    ReAct 思考 → 行动 → 观察 的循环
    Harness 围绕模型的工程外壳：上下文、工具接口、安全约束、验证纠正
    观察空间 / 动作空间 模型与世界的「输入接口」/「输出接口」
