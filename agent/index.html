    AI Agent 可视化入门

    把《深入理解 AI Agent》做成看得懂的图 —— 面向初学者的可视化笔记，源自李博杰原著（Apache-2.0 开源）。

    Agent LLM 上下文 工具 RAG MCP

    🎮 亲手体验：Agent 是怎么工作的¶

    ⚡ 一句话理解 Agent¶

    Agent = LLM + 上下文 + 工具 —— 也就是 大脑 + 眼睛 + 手脚。

    Agent = LLM（大脑）+ 上下文（眼睛）+ 工具（手脚）· 来自原书

    🧠 大脑 · LLM

    大语言模型，负责理解意图、思考规划、做决策。策略

    👀 眼睛 · 上下文

    Agent 每个决策点能看到的所有信息：用户消息、系统提示、工具结果……观察空间

    🦾 手脚 · 工具

    Agent 能做的所有事：调 API、跑代码、搜网页、发消息……动作空间

    为什么这三件套这么重要？

    模型只负责"想"，要想得准，得让它 看得到（上下文里要有足够信息）；想干实事，得让它 够得着（有工具能改变世界）。很多看起来"模型不够聪明"的问题，其实只是"看得不够多"或"够得着的东西太少"——把信息装进上下文、把操作封装成工具，任务就变得可解了。
